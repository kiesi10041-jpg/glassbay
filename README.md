# 잔향 04:17 — 유리만 v5.3

## GitHub에 올리기
압축을 풀면 바로 index.html이 보입니다. 폴더째 감싸서 올리지 말고, 압축 안의 파일과 assets 폴더를 기존 index.html이 있는 위치에 함께 올려 덮어쓰세요.
필수 파일: index.html, style.css, data.js, game.js, ui.js, assets/.
이전 story.js·expansion.js 등의 파일이 남아 있어도 새 index.html은 불러오지 않습니다.
별도 서버 코드·설치·API 키 없이 GitHub Pages에서 동작합니다. 폰트와 그림·음악도 외부 CDN에 의존하지 않습니다.

v5.3은 앞서 논의한 스토리·단말기·동료·부상·침식 구조를 이어서 개선한 통합 업데이트입니다. v5 / v5.1 / v5.2의 같은 브라우저 저장 데이터는 유지합니다. v4 저장 데이터는 손상하지 않지만 v5 엔진으로 이어받지는 않습니다.

## 바뀐 흐름
- 하단 고정 메뉴: 현장 / 지도 / 소지품 / 수첩 / ECHO. 메시지를 보다가 지도·소지품으로 바로 전환할 수 있습니다.
- 지도만 장소 사이 이동을 담당합니다. 연결된 장소로 한 곳씩 이동하며, 장면에서는 조사·대화·행동을 합니다.
- 전체 행동 횟수 제한을 제거했습니다. 위기는 개별 사건에서 대응합니다. 메뉴·수첩·지도 열람은 무료입니다.
- 완료한 일회성 행동은 사라집니다. 조건이 부족한 행동은 이유를 표시합니다. 이동은 물품 획득과 분리했습니다.
- 구급상자는 부위를 선택해 치료합니다. 머리·눈은 함께 치료하며, 팔·다리·청각은 각각 치료합니다. 치료한 부상의 시각 효과와 행동 제한도 해제됩니다. 체력만 회복하는 선택은 따로 있습니다.
- 손상은 충격음·짧은 화면 흔들림·부상 이미지·행동 제한으로 나타납니다. 효과 감소와 큰 글자 설정이 있습니다.
- 질문은 발견한 단서에서 열립니다. 추천 질문을 누르면 입력칸에 들어가고 사용자가 보내거나 수정합니다. 인식하지 못한 질문은 비용을 소모하지 않습니다.
- ECHO 너머에는 실제 사람이 있습니다. 메시지의 거짓말 확률은 1~99이며 말투가 진위를 판정하지 않습니다. 수신 답변은 저장돼 다시 열어도 진위가 바뀌지 않습니다.
- 수첩에서 줄거리 / 증거·의문 / 인물 / 탈출 준비 / 엔딩·진상을 구분합니다.
- 주인공은 이름을 모르고 시작합니다. 약국 기록·회관 작업일지와 사진·학교의 행적·숲 관리소·중계실 원본을 엮어 방문 이유와 사건을 알아갑니다. 장소 방문 순서는 고정되지 않습니다. 먼저 가더라도 도구가 필요한 조사·작업의 조건은 표시됩니다.
- 주요 등장인물은 서진·도윤·나래·수호·해원·윤서, 주인공까지 7명입니다. 인물의 기본 정체는 고정입니다. 접속과 선택에 따라 침식과 부상이 진행됩니다.
- 떠난 동료는 다른 장소로 이동합니다. 재회 시 실제 동료·침식 상태·모방체 접근을 관찰합니다. 합류 거절은 관계와 확률을 반영하고 반복 클릭으로 재추첨되지 않습니다.
- 동료마다 정상·부상·변이 이미지를 사용합니다. 모방체가 처음부터 괴물 이미지로 정답을 알려주지는 않습니다.
- 학교의 첫 위협은 반드시 등장합니다. 숲·시장·물가의 돌발 사건은 장소별 관찰 규칙과 후속 선택이 있습니다. 폐역에는 이미 침식된 승객이 있습니다.
- 침식이 높으면 독립된 사진·반사와 시야가 다른 사건이 발생합니다. NPC를 단말기로 인간/괴물 판정하지 않습니다.
- 출구 뒤에도 구조 거점에서 신원과 동행자의 행동, 제출할 증거를 선택합니다. 28개 엔딩은 플레이 중 정해진 상태를 반영합니다.
- 2회차에는 숨겨진 보고서·이전 접속 흔적·나래의 증언·숲 출구, 3회차에는 주인공이 차단을 미룬 이유가 열립니다. 주요 진상은 핵심 증거를 모아 공개, 전체 진상은 모든 엔딩 후 공개합니다.
- 인트로는 같은 브라우저에서 최초 1회만 표시됩니다. 설정에서 다시 볼 수 있습니다.
- 단말기를 끄면 메시지는 남습니다. 폐기하면 메시지·디지털 접속 기록을 잃으며 실물 증거와 물품은 남습니다.
- 배경음악과 이동·충격·획득음은 설정에서 켭니다. 처음에는 꺼져 있으며 사용자 조작 뒤 재생합니다.

## 검사와 한계
`node verify.cjs`로 검사합니다. 실제 지도 이동을 통한 주요 경로, 모든 엔딩의 상태 조건, 위기 선택, 치료, 메뉴, 재회, 저장/재로딩, 이미지 참조를 확인했습니다. 결과는 validation.txt에 있습니다.
검사는 모의 DOM입니다. 실제 iPhone Safari·Android Chrome에서 터치·화면 배치·키보드·스크롤·음악을 검증한 것은 아닙니다. 모바일 구조는 고정 하단 메뉴, 독립 스크롤, visualViewport 대응으로 정리했지만 실기 확인이 필요합니다.
모든 엔딩을 일반 플레이로 처음부터 끝까지 수집한 테스트는 아닙니다. 주요 경로는 실제 행동 순서로, 다른 결말은 조건과 대응 선택을 각각 검사했습니다.
플레이 타임 25~40분은 앞서 논의한 목표이며 아직 실측값이 아닙니다. 회차별 실제 경과 시간은 저장 데이터의 history.minutes에 남습니다. 28개 엔딩은 28개의 독립된 캠페인이 아닙니다.

- game.js: 진행·이동·치료·질문·동료·위기·저장

## v5.3 업데이트 적용
기존 파일이 모두 있다면 glass-bay-v53-update.zip 안의 index.html, style.css, data.js, game.js, ui.js 다섯 파일을 같은 위치에 전부 덮어쓰세요. 하나만 교체하면 구조와 스타일이 섞일 수 있습니다. 전체 설치는 glass-bay-v53-github.zip을 사용합니다. assets 폴더에는 이전 이미지와 교체된 음악을 포함합니다. 반영 후 PC는 Ctrl+Shift+R로 새로고침하세요. 브라우저 저장 공간을 삭제하면 진행도도 사라집니다.

- PC는 장면·등장인물을 왼쪽에 유지하고 오른쪽 현장 묘사·대화·행동만 스크롤합니다. ECHO는 기존 PC 휴대폰 형태, 모바일은 독립 화면을 유지합니다.
- 체력·침식·다음 안내의 거짓말 확률을 각각 숫자와 막대로 표시합니다. 이미 받은 답변의 확률은 그 답변에 저장된 값을 표시합니다.
- 나래를 포함한 여섯 동료는 현재 행동과 단서에 맞는 대사를 사용합니다. 관련 없는 공통 설명을 매번 반복하지 않으며, 새 단서 전에 이미 아는 것처럼 말하던 일부 문장을 정리했습니다.
- 연결된 장소는 단서를 특정 순서로 얻지 않아도 탐색할 수 있습니다. 장소 안의 작업과 출구 준비에 필요한 도구·조건은 유지합니다. 지도 이동과 현장 행동은 구분합니다.
- 인물의 발언을 실제 대화 기록으로 저장합니다. 현장 묘사·행동 결과·대화를 분리하고, 단말기 답변은 ECHO에서 확인합니다.
- 재회한 동료를 기억·물건·움직임으로 따로 조사합니다. 모방체가 기억을 복사한 경우도 있으며, 부상자가 기억을 잘 설명하지 못해도 정체를 바로 단정하지 않습니다.
- 탈출 뒤 동행자를 구조팀에 따로 맡길 수 있습니다. 정상 동료까지 의심하면 관계 손실이 남습니다. 동행 상태를 바꾼 뒤 최종 결말을 결정합니다.
- 빈사 상태 구급상자는 체력 35를 확보하고 기존 부상은 남깁니다. 필터와 원본으로 완전 침식에서 회복한 뒤에도 연결을 계속 사용하면 다시 위기를 맞을 수 있습니다.
- 실패 원인과 다음 확인할 단서를 해당 항로에 맞췄습니다. 자유 탐색을 막는 단일 목표 문구를 여러 실마리 안내로 바꿨습니다.
- v5 / v5.1 / v5.2 저장 키를 유지합니다. 새로운 동료 관찰 정보는 필요한 때 추가됩니다. 교체된 음악과 기존 이미지 포함.

검증: 46개 자동 검사 그룹 통과. 주요 5개 탈출 경로는 실제 행동·지도 이동으로, 20개 탈출 결말은 상태 조건으로, 8개 비탈출 결말은 대응 선택으로 검사했습니다. 전체 28개 엔딩을 처음부터 끝까지 일반 플레이한 결과는 아닙니다. PC 읽기 영역·모바일 스크롤 검사는 모의 DOM이며 실제 브라우저 배치·터치·오디오 검증은 미완료입니다.

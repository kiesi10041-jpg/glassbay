## v4 — ECHO와 판단의 공포
총 60개 장면, 13개 지역, 28개 엔딩. HTML/CSS/JavaScript로 동작하며 서버나 API 키가 필요 없습니다.
추가 필수 파일: concept-data.js, narrative.js. 기존 파일 일부만 교체하지 말고 이번 ZIP의 전체 내용을 업로드하세요.

ECHO는 처음에는 친근한 탈출 도우미이며, 사용에 따른 침식과 거짓말 확률 상승으로 말투와 선택지 표현이 달라집니다. 거짓말 확률은 1~99%입니다. 각 답변과 수신 안내의 실제 진위는 별도로 추첨되고 저장됩니다. 높은 확률에서도 진실이, 낮은 확률에서도 거짓이 나올 수 있습니다. 원본 규정·수위표·점검판과 대조해야 합니다.

나래는 연결을 거부하고 수호는 신호를 숭배합니다. 동행자의 동기화·신뢰·불안·부상은 개별적으로 진행됩니다. 폐역에는 거짓 항로를 믿었던 변이 생존자가 등장합니다. 플레이어 선택과 질문 뒤에는 플레이어, 동료, ECHO의 대화가 누적됩니다.

침식 50 이상에서 정상인 동료와 기록보관소/약국에 들어가면 시야 오판 분기가 발생할 수 있습니다. 즉석 사진과 반사에는 정상인 모습이 남습니다. 회복하거나 끝까지 자신의 시야만 믿는 행동이 새 엔딩 27/28을 결정합니다. 실물 사진은 단말기 폐기로 삭제되지 않습니다.

인트로는 최초 한 번만 표시됩니다. 같은 브라우저에서 다음 실행/회차에는 자동으로 건너뛰며 설정에서 다시 볼 수 있습니다. 효과 감소 설정은 화면 균열·침식 문구·색 왜곡을 줄입니다.

검사: `node verify-v3.cjs` (모의 DOM에서 기존 탈출, 연결, 부상, 동기화, 저장, 스크롤 복원 호출, 신규 확률/시야 분기 확인). 실제 모바일 Safari/Chrome의 화면 배치와 터치·오디오 재생은 별도 실기 확인이 필요합니다. 스크롤 검사는 실제 모바일 브라우저 검증을 대신하지 않습니다.

# 잔향 04:17 — 유리만 v3 탐험 확장판

## GitHub 업로드
압축 안의 파일과 assets 폴더를 저장소 최상위에 모두 올립니다. 기존 같은 이름 파일은 덮어씁니다.

필수: index.html, style.css, story.js, expansion.js, game.js, explore.js, assets/, .nojekyll
신규 스크립트 expansion.js와 explore.js를 빼면 지도와 확장 시스템이 작동하지 않습니다.

GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save.
설치·빌드·서버·API 키 없이 실행됩니다. 브라우저 캐시 때문에 이전 화면이 보이면 강력 새로고침하거나 새 탭으로 접속하세요.

## 조작
- 지도: 구역을 눌러 경로와 행동 비용을 확인한 뒤 이동
- 상태: 부상 부위·피로·동료 체력·신뢰·불안 확인, 치료·식량·차폐 필터 사용
- 장면: 이미지 위 표식 또는 아래 선택지로 조사, 주변 살펴보기로 확대
- 단말기: 버튼으로 꺼내기/내려놓기. 현장·물품·신호·동료·검증 주제 선택 또는 직접 입력
- 환경음 켜기: 환경 바탕음·발소리·무전·경보를 켬. 설정에서도 변경 가능

## 침식과 노출
침식은 누적 동기화, 위치 노출은 현재 수색 위험입니다. 반복 질문은 부담이 커집니다.
위치 노출 60에서 수색자 접근. 침식 45 이상에서는 자료 왜곡, 65 이상에서는 동료 불신과 이동 중 노출 증가.
높은 침식에서 획득/사용하는 기록은 현장 원본 대조가 필요할 수 있습니다.
차폐 필터·렌즈·휴식으로 위험을 낮출 수 있습니다. 단말기 폐기 시 저장 자료도 사라집니다.

## 질문
직접 입력은 게임 내부의 주제별 응답 시스템입니다. 실제 생성형 AI와 연결되지 않습니다.
게임 화면에는 기술 설명을 상시 표시하지 않습니다. 모호한 질문은 미전송 처리하여 시간·침식을 소모하지 않습니다.

## 저장 호환
이전 v2 진행 상태는 새 확장 규칙과 달라 가져오지 않습니다. 이전 엔딩 수집 기록은 같은 주소에서 유지합니다.
v3 진행·회차는 현재 브라우저에 자동 저장됩니다. 다른 기기와 동기화되지 않습니다.

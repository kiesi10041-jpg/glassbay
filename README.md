# 잔향 04:17 — 유리만

기억을 잃은 채 바닷가 마을에서 깨어났다. 손목에는 이름 대신 **0417**이 적혀 있다.
단말기 너머의 누군가가 나갈 길을 알려 준다. 첫 안내는 나를 살렸다. 다음 안내도 믿어도 될까?

장소를 탐색하고 사람들의 말과 현장의 흔적을 비교하며 탈출하는 스토리 기반 생존 공포 게임입니다.
말을 믿는 것, 동료와 걷는 것, 무사히 마을을 나오는 것은 서로 다른 선택입니다.

## v5.8 — 숨과 충격

- 괴물 접근에는 짧은 거친 호흡, 충격에는 숨을 들이켜는 소리, 붙잡힘 전환에는 짧은 합성 비명 효과를 연결했습니다.
- 체력 35 이하 이동 시 호흡을 재생합니다. 호흡은 9초, 일반 음성은 4.5초 간격을 두고 높은 우선순위 비명이 이전 호흡을 중단합니다. 상시 반복 루프는 아닙니다.
- 음성 재생 중 배경음악을 낮춥니다. 전체 소리와 숨소리·비명을 각각 끌 수 있고, 다른 탭으로 이동하면 음성을 멈춥니다. 기본 전체 소리 설정은 기존대로 유지합니다.
- 머리·눈 충격은 순간 초점 흐림, 다리는 아래로 꺾이는 장면, 팔은 짧은 흔들림으로 표시합니다. 선택지 위치는 움직이지 않습니다. 효과 줄이기 설정과 시스템의 동작 줄이기를 따릅니다.

음성은 직접 합성한 잡음·발성 질감이며 실제 배우의 녹음이 아닙니다. 자동 검사 94개 그룹 통과. 재생 제어는 모의 오디오 검사이며 실제 기기의 음질·음량·자동재생 정책은 청취 검증하지 못했습니다.

## v5.7 — 행동이 이야기로 이어지도록

- 도입에서 방을 떠나야 할 징후와 광장·약국으로 갈 이유를 연결했습니다.
- 치료 기록 → 회관 작업반, 학교 자리표 → 숲 관리소, 사진 → 중계실 원본으로 이어지는 근거를 정리했습니다. 지도 이동 조건은 추가하지 않았습니다.
- 숲에 먼저 가도 이전 장소의 단서를 이미 봤다고 말하지 않습니다. 발견한 단서가 있을 때만 해당 연결 설명을 덧붙입니다.
- 학교를 떠난 사실과 마을 밖으로 탈출한 사실을 구분하고, 비상문이 외부 대피 통로로 연결된다는 설명을 보완했습니다.
- 괴물 조우 뒤 직접 본 징후를 수첩에 남깁니다. 정상 동료가 함께 있으면 인물별 반응이 이어지고 새 부상에는 치료 안내가 남습니다. 같은 종류의 첫 설명을 반복하지 않습니다.
- 부두·등대·폐역·변전소·저류조의 확인할 목표를 현재 단서에 맞춰 표시합니다.
- 신원은 사진·작업일지·원본 카드를 대조한 뒤 확인합니다. 엔딩은 기존 32개이며 저장 키를 유지합니다.

자동 검사 92개 그룹 통과. 실제 브라우저의 화면·터치·오디오 및 완주 시간은 이번 검증에 포함하지 않았습니다. 기존 저장의 과거 대화는 소급 변경하지 않습니다.

## v5.6.1 — 이름을 알아가는 순서

초반 수첩의 이름 선공개를 제거했습니다. 작업일지는 번진 이름과 닮은 서명만 보여주고, 사진과 원본 카드를 대조해야 신원을 확인합니다. 미확인 사진 인물의 이름과 메모·녹음의 성급한 신원 단정도 정리했습니다. 기존 저장에서 이미 읽은 대화는 소급해서 바꾸지 않습니다.

## v5.6 — 보이는 위협, 이어지는 대화

- 막힌 선택지의 설명과 괴물 손 이미지를 별도 영역에 배치했습니다. 불투명한 설명 상자가 손가락을 덮던 구조를 제거했습니다.
- 모바일 괴물 이미지의 크기와 위치를 장면 안에서 직접 지정하고 위협 장면을 확대했습니다. 작은 머리만 화면 아래에 남던 배치를 수정했습니다.
- 여섯 인물의 첫 만남과 후속 대화를 다시 구성했습니다. 나래는 반말, 다른 인물은 존댓말을 기본으로 유지하며 관찰과 속생각은 발언과 분리합니다.
- 다른 사람의 연락을 읽거나 직접 만나야 위치 질문이 열립니다. 괴물 위치도 형체를 본 뒤에 묻습니다. 아직 모르는 대상의 위치 질문에는 침식 비용을 부과하지 않습니다.
- 침식 설명은 나래·서진에게 후속 질문으로 들을 수 있습니다. 동행 중 위기 답변에서 혼자 있다고 말하던 공통 문구도 정리했습니다.
- 회관 열쇠와 중계소 열쇠를 어느 순서로 얻어도 다른 열쇠의 선택지가 사라지지 않습니다. 완료 기록을 장소별로 구분합니다.

v5 계열 저장을 유지합니다. 엔딩 수는 32개로 동일합니다. 자동 검사 88개 그룹을 통과했지만 실제 모바일 화면·터치와 전체 플레이 시간은 아직 실기 검증하지 못했습니다.

## v5.5 — 제보와 흔적

- **질문 선택:** PC 단말기의 추천 질문을 줄바꿈한 격자로 표시합니다. 가로 스크롤이 없어지고 긴 질문도 읽을 수 있습니다.
- **대조 결과:** 받은 안내, 확보한 기록, 일치·충돌한 내용을 한 화면에서 확인하고 사건수첩에 남깁니다. 확인한 답변만 판단하며, 다른 답변이나 응답자의 정체까지 보장하지 않습니다.
- **인물 기록:** 처음 확인한 물건의 특징과 이후 관찰 결과를 나란히 볼 수 있습니다. 회차별 세 가지 특징 변형과 이전 회차 기록이 있으며, 관찰한 차이가 생기면 작은 표시가 붙습니다. 숨겨진 정체를 미리 알려주는 표시는 아닙니다.
- **대사:** 서진이 마지막으로 해원을 본 장소부터 답합니다. 첫 만남에서 동행 약속이나 물건 설명을 한꺼번에 읽던 구성을 정리했습니다.
- **침식 설명:** 초반 나래 또는 서진의 대화로 침식과 몸의 부상, 연결 중단·휴식·필터의 차이를 설명합니다.
- **질문의 대가:** 낮은 침식에서는 2~5, 중간에서는 4~8, 높은 상태에서는 6~11이 기본 비용입니다. 최근 같은 질문을 반복하면 추가 비용 범위를 보내기 전에 표시합니다. 받은 답변에는 실제로 정해진 비용을 남깁니다.
- **거짓말 확률:** 현재 상태에 따른 예상 범위 안에서 답변마다 확률을 정합니다. 범위와 값은 1~99%이며, 답변의 말투와 진위는 따로 결정됩니다. 새로고침·메뉴 열람으로 이미 받은 답변을 다시 추첨하지 않습니다.
- **돌아다니는 괴물:** 괴물은 연결된 길을 따라 이동합니다. 생김새와 활동 구역의 차이는 유지하며 대피소·약국은 이동 대상에서 제외합니다. 학교의 첫 조우는 규칙을 배우는 장면으로 남습니다.
- **위치 제보:** ECHO에 생존자·괴물의 위치를 물을 수 있습니다. 맞거나 틀린 제보, 이미 이동해 오래된 정보가 섞일 수 있습니다. 제보 시점을 표시하고 지도에 표시할 수 있으며, 직접 마주친 결과는 별도로 남깁니다.
- **표현:** 단말기 제목은 ‘ECHO · 메시지’, 닫기 버튼은 ‘단말기 닫기’로 바꿨습니다. 윤서를 확인하면 이름을 표시합니다.

괴물 이동과 답변은 진행 데이터에 저장됩니다. 메뉴를 열어 위치가 바뀌거나, 같은 대조로 보상을 반복 받지는 않습니다. v5 계열 진행을 이어받으며 기존 관찰 기록에 없던 세부 특징을 과거에 이미 봤다고 만들어 넣지 않습니다.

## v5.4 — 손이 길을 막는 밤

이번 업데이트는 **화면에 나타나는 위협과 실제 선택의 결과를 연결**하는 데 집중했습니다.

| 부분 | 달라진 점 |
| --- | --- |
| PC·모바일 화면 | 장면과 등장인물을 남겨두고 대화·선택 영역을 따로 스크롤합니다. PC ECHO는 휴대폰 형태를 유지합니다. |
| 색상·글자 | 현장 설명, 인물 대화, 위기를 구분하고 본문·선택지·상태 수치를 키웠습니다. 모바일 상태 카드는 이름과 숫자를 두 줄로 표시합니다. |
| 대화 등장 | 새 대화가 짧게 나타납니다. 같은 화면을 다시 열 때 등장 효과를 반복하지 않습니다. 지난 현장 설명은 펼쳐서 다시 볼 수 있습니다. |
| 괴물 | 학교·숲·시장·물가에 서로 다른 괴물 4종이 전경으로 나타납니다. 움직임과 대응 규칙도 다릅니다. |
| 닫힌 선택 | 괴물의 손이 가린 길은 실제로 선택할 수 없습니다. 높은 침식도 일부 선택을 가릴 수 있으며, 다른 행동이나 화면에서 손을 떼는 대응이 남습니다. |
| 붙잡힌 뒤 | 부상, 물품 손실, 동료의 부상을 대가로 빠져나갈 기회가 생깁니다. 살아났다고 이전 상태로 돌아가는 것은 아닙니다. |
| 사망 분기 | 막힌 길을 다시 택했을 때의 괴물 사망 엔딩 4개가 추가됐습니다. 전체 엔딩은 32개입니다. |
| ECHO | 현재 괴물의 징후에 맞춰 응답합니다. 친절한 말투의 잘못된 안내도 있으며, 추천 질문은 입력칸 위에서 고를 수 있습니다. |
| 동료·주인공 변화 | 공격하는 모방체와 완전 동기화된 주인공의 변한 모습이 현장에도 나타납니다. |

## 살아남는 데는 대가가 있습니다

괴물과 처음 마주쳤을 때는 움직임을 살피거나 먼저 거리를 벌릴 수 있습니다.
길이 막힌 뒤에는 눈앞의 징후를 보고 다른 대응을 골라야 합니다.
붙잡혀도 빠져나갈 수 있지만 팔을 다치거나, 필요한 물건을 놓거나, 동료가 대신 다칠 수 있습니다.

단말기의 말투만으로 안전을 판단할 수 없습니다. 이미 받은 답변의 거짓말 확률은 다시 열어도 바뀌지 않습니다.
실물 단서, 함께 나눈 기억, 손에 든 물건, 실제 움직임을 비교할 수 있습니다.

현재 동료 구조 분기의 대가는 **동료 부상**입니다. 동료가 목숨을 잃는 희생 분기는 다음 개선 논의 대상이며, 이번에 구현한 기능으로 안내하지 않습니다.

## 이전 업데이트에서 이어지는 내용

- 연결된 장소를 자유롭게 탐색하고, 도구·증거가 필요한 행동에는 조건을 표시합니다.
- 한 번 마친 조사는 선택지에서 사라집니다. 전체 행동 횟수 제한은 없습니다.
- 부상을 치료하면 해당 시각 효과와 행동 제한이 함께 사라집니다. 침식은 별도로 관리합니다.
- 떠난 동료와 다른 장소에서 재회할 수 있습니다. 합류 여부와 변화는 이전 행동의 영향을 받습니다.
- 탈출 후에도 자신의 신원, 동행자의 행동, 제출할 증거를 선택합니다.
- 회차가 늘어나면 보고서와 추가 증언이 열립니다. 사건 기록과 엔딩은 같은 브라우저에 남습니다.

v5 계열의 기존 진행은 유지됩니다. 기존 28개 엔딩을 모두 확인해 진상을 열었던 플레이어는 확장 후에도 진상 열람이 유지됩니다.

## 현재 확인 범위

주요 탈출 경로, 새 괴물의 생존·사망 분기, 부상·물품 손실, 저장 후 위협 단계 유지, 선택 제한을 자동 검사했습니다.
실제 PC·모바일 브라우저의 배치·터치·오디오와 플레이 시간·긴장감은 아직 실기 플레이로 검증하지 못했습니다.

다음 개선은 반복 조우의 변화, 장소를 다시 찾아갈 이유, 동료의 희생과 후일담, 탈출 경로의 개연성을 중심으로 논의 중입니다. 확정된 추가 기능은 아닙니다.

자세한 버전 기록은 [CHANGELOG.md](CHANGELOG.md), 제작 이미지 정보는 [ASSETS.md](ASSETS.md)에 있습니다.
